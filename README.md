## 🚀 Featured Projects

### 🔎 [SnapFind](https://github.com/shawnaks/SnapFind) — AI-assisted lost & found platform
A community-powered platform that reunites people with lost items through photo-first posting and image search.

- **Stack:** React 19, TypeScript, Vite, Supabase (Auth / Postgres / Storage), FastAPI, PyTorch (ResNet-18)
- 🤖 Auto-categorizes items across 12 classes with a CNN, plus search-by-image
- 🔐 Email/password auth, profiles, personal dashboards, and one-click contact to posters

### ✈️ [Flight Fare Optimizer](https://github.com/shawnaks/Flight-Fare-Optimizer) — graph search over U.S. air travel
Models 186 U.S. airports as a weighted graph to find the optimal route between any two cities (MATH 3012, Georgia Tech).

- **Stack:** Python, pandas, NumPy, Matplotlib, Jupyter
- 🧠 BFS, DFS, Dijkstra, and a custom layover-aware Dijkstra implemented from scratch (no graph libraries)
- 📊 Benchmarked on 25,000 routes — a modified Dijkstra nearly matches BFS path length at near-Dijkstra cost

### 🏓 [Pong](https://github.com/shawnaks/Pong) — the classic, rebuilt in one Python file
A compact, zero-asset recreation of the arcade classic.

- **Stack:** Python, pygame
- 🤖 Ball-chasing bot opponent, 4 difficulty levels, and angle-based rebounds
- 📦 Buildable standalone Windows executable
